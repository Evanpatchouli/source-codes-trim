# 源码整理器

![软件截图](https://evan-oss-bucket1.oss-cn-hangzhou.aliyuncs.com/source-coudes-trim/036229dbaafed37f8df694f538b98fc3.png "软件截图")

## 项目简介

源码整理器是一个用于整理源码的工具，可以将源码中的注释、空行等无关内容去除，使源码更加简洁。可用于申请软件著作权、专利等。

使用的技术栈为`Tauri 2` + `Vite` + `React` + `ChakraUi`。

## 使用方法

1. 选择源码根目录
2. 点击获取文件
3. 按需要拖动文件或目录调整顺序，然后点击整理源码
4. 在右侧文本框中查看整理后的源码，文本框右上方会显示行数和复制按钮

整理器识别 JavaScript、JSX、TypeScript、TSX、Rust、Python、C 和 C++ 的语法，清除普通注释及可安全去除的空白。字符串内的 URL、多行文字、Python 整除和语法指令会保留。遇到其他格式或无法可靠解析的源码时，保留该文件原文。

包含、排除两栏均可用换行或 `|` 分隔规则。包含栏留空表示选中全部。只写取反规则时，从全部文件中去除匹配项。排除栏在包含栏之后生效。同一栏按顺序应用规则，`!` 可反转此前的匹配，例如在排除栏写 `*.ts | !only.ts`。以 `/` 开头限定根目录，以 `/` 结尾只匹配目录，例如 `/target/`。排除整个目录会跳过其子树。要保留其中的个别文件，请让父目录可遍历。

扫描时同级目录排在文件前，同类按名称排序。遇到无法读取的子目录、链接或特殊文件时，其余文件仍可整理。展开“扫描跳过”可以查看路径和原因。

拖动文件或目录的手柄，可以把它放在目标行之前、之后，或放入目标目录。整个目录连同子项一起移动。用键盘聚焦手柄后，按 `Alt + ↑` 或 `Alt + ↓` 可调整同级顺序。整理时按文件树从上到下依次拼接，遇到目录就先处理其子项。折叠目录也会参与整理，已排除的节点会被跳过。拖动调整的是本次整理顺序，每个文件仍从其原路径读取。同一项目重新获取文件时，会保留已有顺序并列出新增和缺失文件。

排好文件树后，点击“保存方案”可生成 `.sctplan` 文件，保存筛选条件、手动排除项和树的排列。下次先选择项目根目录，再点击“打开方案”。方案按相对路径识别文件，整个项目换目录后也可继续使用。扫描会自动略过方案文件。

切换根目录或调整筛选条件后，需要重新获取文件。改变树中的选择后，点击“整理源码”生成对应的结果。

文件树中的眼睛按钮只切换当前节点。排除目录会跳过它的所有子项。重新包含目录后，会恢复子项原有的选择。排除 `a.ts` 不影响同级的 `a.tsx`。

整理完成后可查看成功处理的文件数。非 UTF-8 文本、含空字节的文件和读取失败的文件会列在“整理跳过”中，包括具体路径和原因。

行数按完整结果统计。结果超过 256 KiB 时，界面只显示能容纳的完整 UTF-8 字符，“复制预览”复制可见部分，“导出完整内容”可保存全部源码。在清除结果、重新整理或关闭应用之前，可以重复导出。

从标题栏菜单选择“检查更新”可查询 GitHub 的发布信息。发现新版本后，“前往下载”会打开本项目的发布页面。请求失败会显示错误原因，可以重新检查。

## 本地验证

- 安装前端依赖用 `npm ci`。使用 Node.js 22.18 或更高版本运行 `npm test`，可直接测试 TypeScript 模块。
- `npm run typecheck` 检查应用与 Vite 配置。`npm run build` 会先运行类型检查，再生成前端产物。
- Windows 使用 MSVC 工具链执行 `cargo +stable-x86_64-pc-windows-msvc test --locked --manifest-path src-tauri/Cargo.toml`，覆盖核心逻辑与 Tauri IPC。其他桌面平台可使用对应的原生 Rust 工具链。

## 收集 Windows 发布包

完成 Windows x64 的 Tauri 发布构建后，运行 `npm run collect-release`。脚本检查便携版主程序、说明文档、许可证和当前版本的 MSI、NSIS 安装包。三个 ZIP 写入并校验成功后才替换 `release/`。缺少输入时命令返回失败，上一版发布包仍可使用。

如果进程在替换目录时意外中断，先确认没有其他收集任务在运行。若 `release/` 缺失且 `.collect-release/previous/` 存在，将后者恢复为 `release/`。核对发布文件后，移走遗留的 `.collect-release/` 目录即可重试。
