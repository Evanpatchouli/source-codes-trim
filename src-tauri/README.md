# 源码整理器

## 项目简介

源码整理器是一个用于整理源码的工具，可以将源码中的注释、空行等无关内容去除，使源码更加简洁。可用于申请软件著作权、专利等。

使用的技术栈为`Tauri 2` + `Vite` + `React` + `ChakraUi`。

## 使用方法

主窗口的初始尺寸和最小尺寸均为 1024 × 780 逻辑像素，可继续放大或最大化。

1. 选择源码根目录
2. 点击获取文件
3. 按需要拖动文件或目录调整顺序，然后点击整理源码
4. 在右侧文本框中查看整理后的源码，文本框右上方会显示行数和复制按钮

用手柄将节点拖到目标行之前、之后或目录内。拼接顺序与树从上到下的顺序一致，折叠目录的子文件也会按序参与，已排除项会被跳过。同一项目重新扫描时会保留已有顺序并报告新增、缺失文件。

“保存方案”将筛选条件、排除项和树的顺序保存在 `.sctplan` 文件中。项目换目录后，先选择新的根目录，再点击“打开方案”即可按相对路径恢复。

包含、排除规则以换行或 `|` 分隔。排除栏优先，同一栏按顺序应用，`!` 反转匹配。以 `/` 开头限定根目录，以 `/` 结尾指定目录。示例：排除 `/target/ | *.ts | !only.ts` 会跳过根目录的 target 文件夹，以及除 only.ts 以外的 .ts 文件。

普通注释的清理支持 JS/JSX、TS/TSX、Rust、Python、C 和 C++。不支持的格式或无法可靠解析的文件保留原文。

扫描或整理跳过文件时，点击相应的整行标题可展开或收起原因列表。用键盘聚焦标题后，按 Enter 或空格也可切换。行数来自完整输出。成功整理后，“导出 TXT”可保存任意大小的全文，包括空结果。超过 256 KiB 时只预览开头部分，导出仍保留全文。

整理后文件树会标注各文件在全文中的行号范围。点击文件可查看本次整理的内容，长文件可以分段查看。成功处理但没有增加输出行的文件标为“0 行”。

点击“按行导出”可按起止行或首尾行数保存 TXT。起止行均包含在内，首尾重叠部分自动去重。核对显示的实际行数后保存。使用“导出 TXT”仍可直接保存全文。
